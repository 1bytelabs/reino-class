Plugin privado para controle de presenca presencial do Reino Class.

== Recursos ==
* Aulas vinculadas opcionalmente aos cursos do Tutor LMS.
* Chamada temporaria de 5 a 180 minutos.
* Codigo numerico de seis digitos e link por QR Code.
* Um registro por aluno e aula.
* Perfis de rede armazenados apenas como hashes.
* Relatorio por aula e exportacao CSV para administradores.
* Pagina de confirmacao criada automaticamente.

== Instalacao ==
1. Envie o ZIP em Plugins > Adicionar plugin > Enviar plugin.
2. Ative o plugin.
3. Use o menu Reino Class no painel.
